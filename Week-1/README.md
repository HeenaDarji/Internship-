# Week 1 – Titanic Data Cleaning Project

## Objective

The objective of this project is to clean and preprocess the Titanic dataset using Python and prepare the data for further machine learning tasks.

## Tasks Performed

- Loaded the Titanic dataset using Pandas.
- Explored the dataset using info() and describe().
- Identified and handled missing values.
- Applied mean/median/mode imputation where required.
- Encoded categorical variables using:
  - LabelEncoder
  - OneHotEncoder
- Visualized the age distribution using Matplotlib/Seaborn.
- Saved the cleaned dataset as a new CSV file.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files

- week1 task-checkpoint.ipynb – Jupyter Notebook containing the complete data cleaning process.
- Titanic_Cleaned.csv – Cleaned Titanic dataset.

## Outcome

Successfully cleaned and preprocessed the Titanic dataset and generated a cleaned CSV file ready for further machine learning applications.
